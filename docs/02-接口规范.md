# Blancall 小程序 · 接口规范（v1）


> 传输：HTTPS + JSON；Base URL：`https://<api-host>/api/v1`
> 鉴权：`Authorization: Bearer <sessionToken>`（登录接口除外）
> 统一响应：成功 `{ "ok": true, "data": ... }`；失败 `{ "ok": false, "code": "...", "message": "可读文案" }`

## 0. 错误码

| code | 说明 |
|---|---|
| `UNAUTHORIZED` | 未登录或会话过期 |
| `AI_BUDGET_EXCEEDED` | 平台当日 AI 预算已用尽（返回 budget/used）；次日恢复 |
| `SPACE_QUOTA_EXCEEDED` | 空间不足（返回 need/used/total） |
| `UPSTREAM_FAILED` | 上游（大模型/解析/微信）失败，可重试 |
| `INVALID_ARGUMENT` | 参数校验失败 |
| `CONTENT_REJECTED` | 内容安全未通过 |
| `SYNC_CONFLICT` | 同步冲突（返回服务端版本） |

## 3. 数据同步（核心学习数据）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/sync/push` | body `{deviceId, ops:[{entity, op:"upsert"|"delete", uuid, updatedAt, payload}]}` → `{results:[{entity, uuid, status:"applied"|"conflict", rev, serverUpdatedAt}], serverTime}`；客户端对 `applied` 与 `conflict` 均视为已解决并出队（conflict 表示服务端版本胜出，随后由 pull 对齐） |
| GET | `/sync/pull?cursor=&limit=500` | → `{items:[{entity, uuid, op, payload, rev, updatedAt}], nextCursor, hasMore}` |

**实体与载荷字段**（与客户端本地结构一致，客户端生成 uuid/updatedAt）：

| entity | payload 要点 |
|---|---|
| `article` | title, content, author, autoIndent, createdAt, updatedAt |
| `tag` | name, color, order |
| `tag_link` | articleUuid, tagUuid（uuid = `${articleUuid}:${tagUuid}`） |
| `practice_record` | articleUuid, mode, totalBlanks, correctCount, mistakes[], timestamp, duration, similarity, rating, weakHints, strongHints, answeredSentenceStarts[], mistakeSentenceIndices[] |
| `practice_state` | articleUuid, mode, status, totalBlanks, answeredCount, answers{}, dictationInput, clozeJson, configUuid, lastPracticeTime |
| `fsrs` | key（`article` 或 `s:<articleUuid>:<hash16>`）, difficulty, stability, due, lastReview, reviewCount, lapses, lastRating |
| `custom_cloze` | articleUuid, name, createdAt, mode, levels[], contentHash, blanks[{s,a,b}], configUuid, order |
| `mask_config` | articleUuid, name, createdAt, contentHash, spans[{p,a,e,c}], selected |
| `reader_prefs` | articleUuid, bgMode, fontId, fontWeight, fontPx, lineHeight, layoutMode, occlusionEnabled, occlusionMode, occlusionColor, occlusionCustomConfigUuid |
| `home_layout` | cards[{id,type,refUuid,articleUuid,colSpan,rowSpan,pinned,lockRow,lockCol,title}] |
| `app_settings` | 全部本地偏好键（外观/练习/阅读/AI 开关/提醒等；不含密钥） |
| `study_stat` | date, practiceSeconds, readingSeconds, practiceCount（用于学习时长排行榜；客户端聚合上报） |

**冲突策略**：实体级 LWW（比较 `updatedAt`，服务端 `rev` 自增）；`practice_record` 追加写天然无冲突；删除写墓碑（`op=delete`，保留 30 天）。

## 4. 上传（文档 / 字体，个人私有）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/uploads/documents` | multipart `file`（≤50MB）→ `{id, name, ext, size, status}`；PDF 需 `pdf_import` 权益 |
| GET | `/uploads/documents` | 我的文档列表 |
| DELETE | `/uploads/documents/:id` | 删除（释放空间） |
| POST | `/uploads/documents/:id/parse` | 触发/获取解析结果 → `{title, paragraphs[], plainText}`（导入到背诵用） |
| POST | `/uploads/fonts` | multipart `file`（TTF/OTF ≤20MB；校验 sfnt 魔数）→ `{id, family, url}` |
| GET | `/fonts` | 我的字体 |
| DELETE | `/fonts/:id` | 删除 |
| POST | `/uploads/avatar` | multipart `file`（jpg/png/webp ≤2MB）→ `{url}`；转存到对象存储后由前端写入 `PATCH /me` 的 `avatar` |

约束：所有上传先校验登录态 → 空间配额 → 内容安全（文档文本 `msgSecCheck`；字体做结构与类型校验）。文件仅本人可访问（下载 URL 带签名，有效期 ≤10 分钟）。头像为小程序「头像昵称填写」得到的临时路径，**必须先经 `/uploads/avatar` 转存**（临时路径下次启动即失效），返回 URL 由存储驱动决定（local 为签名 URL，s3 为预签名/公开 URL）。

## 5. AI（平台代理）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/ai/cloze` | body `{articleText, mode:"SENTENCE"|"WORD"|"REVERSE", strategy, level, extra?}` → `{coords}` |
| POST | `/ai/analysis` | body `{title, mode, accuracy, mistakes[], weakHints, strongHints}` → `{markdown}` |
| POST | `/ai/chat` | body `{sessionId, articleUuids[], messages[]}` → 分块响应（`enableChunked`） |
| GET | `/ai/sessions` / GET `/ai/sessions/:id` / DELETE `/ai/sessions/:id` | 历史 |

要求：输入输出均送内容安全检测；响应体含 `aiGenerated: true`（前端需展示"AI 生成"标识）；**不含联网搜索**。

**完全免费**：所有登录用户可用，无任何使用门槛。唯一限制是**平台级日预算熔断**
（环境变量 `AI_DAILY_BUDGET_CARDS`）：每日全平台 AI 用量上限，用于控制上游成本；
`0` 或未配置 = 不限制。用量按自然日（Asia/Shanghai）写入 `ai_daily_usage` 表并原子自增；
超出预算返回 `AI_BUDGET_EXCEEDED`（HTTP 429），前端文案：「今日 AI 服务已达上限，请明天再试或使用本地算法」。
上游失败自动释放当日预算。
