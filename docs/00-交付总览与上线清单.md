# Blancall 小程序 · 交付总览

> **完全免费**的开放源代码项目。本文档为交付物索引与上线清单。

## 1. 交付物索引

| 交付物 | 位置 | 说明 |

| 数据库 | `server/prisma/` | `schema.prisma`（14 张表）+ 迁移 + seed |
| 部署与联调 | `server/README.md`、`server/scripts/verify-checklist.md` | 环境变量表、启动步骤、curl 冒烟清单 |

## 2. 上线前必须替换/申请

| # | 项 | 位置/说明 |
|---|---|---|
| 1 | 小程序 AppID | `miniprogram/project.config.json` 的 `appid`（当前 `touristappid`） |
| 2 | 云服务 / 后端 | 小程序默认走云端 BaaS：`miniprogram/core/net/cloud.ts` 的三个占位符；或自建 `server/` 后端 |
| 3 | 微信 AppID/AppSecret | 后端 `server/.env`（`WX_APPID`/`WX_SECRET`） |
| 4 | 内容安全 | 后端使用小程序 access_token 调用 `msgSecCheck` |
| 5 | 订阅消息模板 | 公众平台「订阅消息」申请后填写 `WX_SUBSCRIBE_TEMPLATE_ID` |
| 6 | 对象存储 | 后端 `STORAGE_DRIVER=s3` + 桶与密钥；或 `local`（仅开发） |
| 7 | 类目与资质 | 建议「工具-效率/办公」或「教育-教育信息服务」 |
| 8 | 隐私保护指引 | mp 后台按 `docs/05` 的收集项逐条声明；《用户协议》《隐私政策》文案在 `packages/account/pages/agreement` |
| 9 | 素材库内容 | 高考必背 60 篇文本已内置（`miniprogram/core/library/gaokaoTexts.ts`） |
| 10 | AI 供应商与日预算 | 后端 `server/.env`：`AI_BASE_URL`/`AI_API_KEY`/`AI_MODEL`；`AI_DAILY_BUDGET_CARDS`（生产建议设置防成本失控） |
| 11 | 大模型合规 | 使用已备案的境内大模型服务；AI 输入输出均送内容安全检测 |
| 12 | 埋点与日志留存 | 需配置定期清理策略（如 90 天滚动删除） |

## 3. 本地验证命令

```bash
# 小程序：类型检查 + 算法单测 + 页面完整性
cd miniprogram
npm install
npx tsc -p tsconfig.json --noEmit
node --test tests/
cd ..
node scripts/check-pages.js

# 后端（可选，仅自建时）
cd server
npm install
npx prisma generate
npx prisma db push
npm run build
```

## 4. 上线顺序建议

1. 云服务/后端部署（域名/证书/库/对象存储）→ 用 `verify-checklist.md` 跑通接口。
2. 小程序替换 AppID 与云配置 → 开发者工具编译 → 真机体验版（游客功能 + 登录 + 同步 + 上传）。
3. 内容安全与 AI 合规复核：上传/对话/AI 输出的送检与 AI 生成标识。
4. 提审（体验版 → 审核版），灰度发布并开启错误上报与埋点观察。
