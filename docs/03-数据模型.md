# Blancall 小程序 · 数据模型


## 1. 客户端（小程序）本地存储

小程序 Storage 仅存轻量偏好（单 key ≤1MB、总量 ≤10MB）；**正文与学习数据存文件系统**（`wx.env.USER_DATA_PATH`）。

```
USER_DATA_PATH/
├─ db/
│  ├─ articles.jsonl          # 每行一个 Article（uuid 主键）
│  ├─ records.jsonl           # PracticeRecord 追加写
│  ├─ tags.json               # {version, tags[], links{}}
│  ├─ practice_state/<articleUuid>.json
│  ├─ fsrs_state.json         # { "<articleUuid>": {...}, "s:<articleUuid>:<hash16>": {...} }
│  ├─ custom_cloze.json       # {version, articles:{uuid:[config]}}
│  ├─ mask_config.json        # {version, articles:{uuid:[config]}, selected{}}
│  ├─ reader_prefs.json       # {version, articles:{uuid:prefs}}
│  ├─ home_layout.json        # {version, cards[]}
│  ├─ sentence_card.json
│  ├─ ai_history/<sessionUuid>.json
│  └─ sync/oplog.jsonl        # 待同步操作队列（离线队列）
├─ fonts/<uuid>.ttf|otf       # 云端字体缓存 / 本地字体
├─ library/gaokao/pN.txt      # 素材库正文缓存
└─ tmp/                       # 导出与临时文件
```

Storage 键（`wx.setStorageSync`）：`app_prefs`（外观/主题色/练习/阅读/提醒/AI 开关等）、`session`（token/openid/expiresAt）、`entitlements_cache`（权益快照 + 缓存时间）、`sync_cursor`、`device_id`、`local_id_map`（旧自增 id → uuid，一次性迁移用）。

### 实体（与 02-接口规范 §3 一致）

| 实体 | 主键 | 说明 |
|---|---|---|
| Article | uuid（UUIDv7） | title, content, author, autoIndent, createdAt, updatedAt |
| PracticeRecord | uuid | articleUuid, mode, totalBlanks, correctCount, mistakes[], timestamp, duration, similarity, rating, weakHints, strongHints, answeredSentenceStarts[], mistakeSentenceIndices[] |
| PracticeState | articleUuid | mode, status(IN_PROGRESS/COMPLETED), totalBlanks, answeredCount, answers{}, dictationInput, clozeJson, configUuid, lastPracticeTime |
| Tag / TagLink | uuid / `${a}:${t}` | name, color(#RRGGBB), order |
| FSRS 状态 | key | article 级 + `s:<articleUuid>:<hash16>` 句级 |
| CustomCloze | uuid | articleUuid, name, mode, levels[], contentHash(MD5), blanks[{s,a,b}] |
| MaskConfig | uuid | articleUuid, name, contentHash, spans[{p,a,e,c}], selected |
| ReaderPrefs | articleUuid | bgMode, fontId, fontWeight, fontPx, lineHeight, layoutMode, occlusionEnabled, occlusionMode, occlusionColor, occlusionCustomConfigUuid |
| HomeLayout | 单例 | cards[{id,type,refUuid,articleUuid,colSpan,rowSpan,pinned,lockRow,lockCol,title}] |
| SentenceCard | 单例（当日） | date, key, articleUuid, text, start, end, title |
| StudyStat | `date`(YYYY-MM-DD) | practiceSeconds, readingSeconds, practiceCount（本地聚合 → 上报用于排行榜） |

> 迁移改造：原 Android 端自增 id 全部替换为 UUIDv7；`contentHash` 仍用 MD5 校验文章内容；本地写入采用"写临时文件 → 校验 → 替换"避免半写。

## 2. 服务端（PostgreSQL）

| 表 | 关键字段 |
|---|---|
| `users` | id(uuid), openid(unique), unionid, nickname, avatar, rank_visible(bool), credits(int), streak_current, streak_longest, last_checkin_date(date), space_bytes_used(bigint), created_at, deleted_at |
| `sessions` | token(unique), user_id, expires_at, created_at |
| `entities` | user_id, entity, uuid, op, payload(jsonb), rev(bigint), updated_at, deleted(bool)，唯一键 (user_id, entity, uuid) |
| `sync_cursors` | user_id, cursor(bigint)（单调递增服务端序号，`entities.rev` 最大值） |
| `checkins` | id, user_id, date(date), credits_delta, streak_after，唯一 (user_id, date) |
| `credit_ledger` | id, user_id, delta, reason(checkin/reward/...), created_at |
| `leaderboard_snapshots` | id, type(credit/time), period(week/all), period_key, payload(jsonb), generated_at |
| `study_stats` | user_id, date, practice_seconds, reading_seconds, practice_count，唯一 (user_id, date) |
| `uploads` | id(uuid), user_id, kind(document/font), name, ext, size_bytes, storage_key, status(uploaded/parsed/failed), parsed(jsonb), family(font), created_at |
| `ai_sessions` | id(uuid), user_id, title, created_at, updated_at |
| `ai_messages` | id, session_id, role, content, created_at |
| `audit_logs` | id, user_id, action, detail(jsonb), created_at |

## 3. 空间与用量

```
total_space(user) = 300MB（FREE_SPACE_BYTES，统一免费额度）
used_space(user) = users.space_bytes_used
ai_usage(cloze, chars) = ceil(chars / 500)；analysis = 1；chat = 1（仅用于平台级日预算熔断统计）
```

## 4. 学习时长口径（排行榜）

`study_seconds = practiceRecord.duration 累加 + readingSeconds 累加`（与统计页口径一致；由客户端按日聚合后随 `study_stat` 同步实体上报，服务端只做汇总与快照）。
