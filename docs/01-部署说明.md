## 1. 部署前必须确认/办理的事项

| # | 事项 | 责任方 | 说明 |
|---|---|---|---|
| 1 | 企业主体 + 小程序 AppID | 服务商 | 类目建议「工具-效率/办公」；需与后端 AppID 一致 |
| 2 | 服务器 | 服务商 | 建议 ≥2C4G；Docker + Docker Compose 环境；磁盘按素材/导出文件量预留 |
| 3 | **已备案域名 + HTTPS 证书** | 服务商 | 如 `api.example.com`；证书放 `server/certs/fullchain.pem`、`privkey.pem` |
| 4 | 小程序后台域名白名单 | 服务商 | `request` 与 `downloadFile` 均需加入 `https://api.example.com`（若用云对象存储直链，另加其域名） |
| 6 | 内容安全 | 服务商 | `WX_APPID`/`WX_SECRET` + `WX_SECURITY_ENABLED=true`（**不配置将导致审核不通过**） |
| 7 | 订阅消息模板 | 服务商 | 公众平台申请「一次性订阅」提醒模板；模板 ID 写入 `WX_SUBSCRIBE_TEMPLATE_ID`，并**核对模板字段与代码 `data` 键名一致** |
| 8 | 对象存储 | 服务商 | 二选一：① 云 COS/OSS（`STORAGE_DRIVER=s3`，**推荐**）；② 自建 MinIO（compose 已含）或本地磁盘（`local`，需持久卷 + 备份） |
| 9 | AI 供应商与预算 | 服务商 | 建议境内已备案模型（DeepSeek / 通义 / 智谱等），提供 `AI_BASE_URL` / `AI_API_KEY` / `AI_MODEL` |
| 10 | 素材库授权 | 服务商 | 一期仅上线 gaokao 文本（`p1..p60.txt`，已随代码交付于 `server/assets/gaokao/`）；**PDF 与 philo 素材不上线**（D15） |

## 2. 部署步骤（概览，详细命令见 server/README.md §5.5）

```bash
cd server
cp .env.example .env
# 必改：DATABASE_URL、POSTGRES_PASSWORD、STORAGE_URL_SECRET、PUBLIC_BASE_URL、
mkdir -p certs && cp <fullchain.pem> <privkey.pem> certs/
docker compose up -d --build
docker compose logs -f api     # 期望：db push 建表 + 「Blancall API 已启动」
```


若不用 Docker：

```bash
npm install && npx prisma generate && npx prisma db push && npm run build && npm run start
```

## 3. 最小可用环境变量（内测版）

只想先跑通、暂不接 AI：

```
NODE_ENV=production
PORT=3000
PUBLIC_BASE_URL=https://api.example.com
DATABASE_URL=postgresql://...
STORAGE_DRIVER=local
STORAGE_LOCAL_DIR=/data/storage
STORAGE_URL_SECRET=<随机长字符串>
ADMIN_TOKEN=<随机长字符串>
WX_APPID=<小程序AppID>
WX_SECRET=<小程序AppSecret>
WX_SECURITY_ENABLED=true
```

## 4. 部署后验收

1. 逐条执行 `server/scripts/verify-checklist.md` 的 §1～§4（安装/迁移/seed/构建/启动/42 条接口 curl 冒烟）。
2. 重点确认：
   - `/auth/login` 返回的 openid **不是** `dev_` 前缀（说明微信凭证生效）
   - 业务响应中**不出现** `securitySkipped: true`（说明内容安全生效）
   - `/library/gaokao/index` 返回 60 篇目录
   - 学习提醒在配置模板后能收到订阅消息（一次性授权需先在小程序端囤次数）

## 5. 运维要点

| 项 | 建议 |
|---|---|
| 备份 | PostgreSQL 每日全量 + WAL 归档；`STORAGE_DRIVER=local` 时同时备份存储目录 |
| 日志 | 生产输出单行 JSON（`AppLogger`），接入采集；`audit_logs` 表建议 90 天清理策略 |
| 监控 | 容器 `HEALTHCHECK` 已配置；建议另加外部拨测 `/api/v1/library/gaokao/index` |
| 成本控制 | 全局 AI 日预算 `AI_DAILY_BUDGET_CARDS`（每日全平台用量上限，0 = 不限制） |
| 迁移 | 升级时执行 `npx prisma db push` 后重建镜像 |
