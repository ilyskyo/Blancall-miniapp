# Blancall 小程序 · 前端实现规范（页面开发必读）

> 目标：功能等价于 Android 端 Blancall Pro（AI 走后端代理、无联网搜索、无手写）；UI 适配微信规范，不要求像素级照搬。

## 1. 工程约定

- 页面目录：`pages/<name>/index.{json,wxml,wxss,ts}`（分包：`packages/<pkg>/pages/<name>/index.*`）。
- 页面根节点必须是：

```html
<view class="page" style="{{themeStyle}}">
  <nav-bar title="标题" />
  ...
</view>
```

- 页面 `.ts` 在 `onLoad` 中：`this.setData({ themeStyle: themeStyle() })`，并用 `onThemeChange` 订阅主题变化（`onUnload` 取消）。
- tabBar 页面（home/list/overview/library）必须在 `onShow` 里：
  `const tb = this.getTabBar && this.getTabBar(); if (tb) tb.setData({ selected: <index> });`
  索引：home=0、list=1、overview=2、library=3。
- 页面 `.json` 里声明 `usingComponents`：`"nav-bar": "/components/nav-bar/nav-bar"` 等（tabBar 页面还要 `"usingComponents": {}` 且根节点使用 `.page-body--tabbar` 预留底栏空间）。
- 禁止：任何第三方 UI 库、任何写死的颜色（必须用 `var(--*)`）、`innerHTML`。
- 所有异步操作必须 `try/catch`，失败用 `wx.showToast({ title: err.message, icon: 'none' })`；成功可轻提示。

## 6. 验收要点（页面层）

1. 未上线能力入口必须出现 `<lock-mask>` 提示（说明文字），不得直接报错。
2. AI 入口在未登录/无卡时必须给出明确文案与购买入口。
3. 云同步/上传/签到/排行在未登录时走 `requireLogin`。
4. 断点续练：仅"部分提交"落盘；完整提交后 `commitSession` 自动清除。
5. 提示系统必须使用 `nextHint`/`applyStrongHint` 与 10s/5s 计时，不得自定义阈值。
6. 阅读模式遮挡：本地三粒度与自定义配置；深色模式正文背景纯黑。
7. 所有页面在深色模式下无白底残留。
