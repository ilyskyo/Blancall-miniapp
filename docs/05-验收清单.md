# Blancall 小程序 · 「功能等价」验收清单

> 判定原则：**核心流程 / 字段 / 校验 / 状态 / 异常提示 / 权限逻辑与原产品一致**；UI 适配微信规范，不要求像素级照搬。
> 使用方式：逐项验收打勾；差异项必须落在「§4 明确不等价项」范围内，否则视为缺陷。

## 4. 明确不等价项（不作为缺陷）

1. 手写作答与手写识别、手写笔压感（模型授权限制 + 小程序无端侧推理）。
2. AI 联网搜索（产品决定不做）。
3. 用户自配 API 域名与本地 Key 加密（改为平台代理，服务端保管密钥）。
4. 原生 PDF 内嵌渲染（改为后端转分页图或文本模式）。
5. 系统通知（改为订阅消息，到达率弱于系统通知）。
6. 桌面小组件（原产品本就没有）、赞赏区（平台合规不允许）。
7. 系统字体扫描（改为预设 + 云端/导入字体）。
8. 液态玻璃折射效果（降级为模糊 + 半透明 + 高光描边）。
9. 任意目录文件读写（改为聊天文件 + 云端上传）。

## 5. 验收方法与证据

- **算法对拍**：`cd miniprogram; npm test`（当前 **197 项全绿**，含与 Python hashlib 交叉校验）。
- **类型检查**：`npm run typecheck`（app / pages / packages / components / core 全量，等价于微信 TS 插件口径）。
- **静态检查**：`npm run verify`（页面完整性 + WXML/TS 绑定一致性 + 前后端契约一致性 + 路由规范 + 设计令牌 + JSON 语法 + tabBar 选中态 + 练习引擎不变量 + 页面循环内单体查询守卫）。
- **端到端**：微信开发者工具 + 真机（Android / iOS 双端），按 §1–§3 逐项走查并录屏留档。
- **接口联调**：`server/scripts/verify-checklist.md` 中的 curl 冒烟清单。
- **上线前回归**：每轮改动后重跑 `npm run verify` + 关键流程（导入→练习→断点→统计→阅读→遮挡→同步→购买）。
